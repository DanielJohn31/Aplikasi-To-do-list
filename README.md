# Aplikasi-To-do-list

##Deskripsi
Aplikasi sederhana berbabsis PHP untuk mencatat tugas harian 

##Fitur
-Tambah tugas
-Tandai tugas selesai
-Hapus tugas
-Edit tugas

##Struktur folder 
-'index.php' -Halaman utama
-'style.css' -File CSS

##Cara menjalankan
-Salin folder ke 'htdocs/'
-Jalankan XAMPP dan buka di 'http://localhost/todolist
